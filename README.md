🔀 BFF — Agendador de Tarefas
Backend for Frontend (BFF) da plataforma de agendamento de tarefas.
É o ponto de entrada único da aplicação — orquestra as chamadas aos demais microsserviços,
expõe uma API unificada ao cliente e executa um job agendado (Cron) que detecta tarefas próximas
e dispara notificações por e-mail automaticamente.

TECNOLOGIAS UTILIZADAS:

JAVA + SPRING BOOT

SPRING WEB

SPRING SECURITY

OPENFEIGN

FEIGN ERROR DECODER(Tratamento centralizado de erros dos serviços internos)

SPRINT SCHEDULER(Cron para busca e notificação de tarefas)

SPRINGDOC (SWAGGER)

LOMBOK

MAVEN

DOCKER E DOCKER COMPOSE

GITHUB ACTIONS
